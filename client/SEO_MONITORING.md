# SEO Monitoring Playbook

This project is configured for indexing with:
- `https://www.srannalifamily.com/sitemap.xml`
- topic landing pages for Jesus resurrection and Sister Anna Ali early life

## 1) Connect Google Search Console

1. Open [Google Search Console](https://search.google.com/search-console).
2. Add property: `https://www.srannalifamily.com/` (URL prefix property).
3. Verify ownership using one method:
   - DNS TXT record (recommended), or
   - HTML file upload, or
   - HTML tag in site head.
4. After verification, submit sitemap:
   - `https://www.srannalifamily.com/sitemap.xml`

## 2) Validate Key SEO Assets

- Test `https://www.srannalifamily.com/robots.txt`
- Test `https://www.srannalifamily.com/sitemap.xml`
- Run Rich Results Test for:
  - homepage

## 3) Query Group Tracking

Track performance monthly for these query clusters in Search Console Performance report.

### Cluster A: Jesus After Resurrection
- miracles of jesus after death
- jesus life after death
- jesus after resurrection
- jesus resurrection appearances

### Cluster B: Sister Anna Ali Early Life
- early life of sister anna ali
- sister anna ali as a child
- sister anna ali family story
- sister anna ali biography

## 4) Monthly Reporting Template

Capture these metrics per query cluster and per landing page:
- impressions
- clicks
- CTR
- average position

Pages:
- `/`

## 5) Optimization Rules

- If impressions grow but CTR is low, rewrite page title and meta description.
- If position is low and impressions are low, expand on-page content depth and internal links.
- If one query cluster outperforms, publish one additional page in that cluster.
